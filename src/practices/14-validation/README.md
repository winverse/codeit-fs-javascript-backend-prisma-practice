# 유효성 검사

## 문제와 시작 상태

회원가입과 로그인 요청을 검증하는 엄격한 Zod schema를 작성합니다. 시작 schema는 어떤 객체든 허용합니다.

## 수정 파일과 fixture

- 수정: `src/schemas.js`
- 정상·오류 요청: `fixtures/cases.json`

## 실행 진입점

`npm run check:14`

## 성공·실패 기준

정상 요청은 통과하고 이메일 형식, 비밀번호 길이, 빈 이름, 빈 로그인 비밀번호, 알 수 없는 필드를 거부하면 성공합니다. 오류 요청 하나라도 통과하면 실패합니다.
