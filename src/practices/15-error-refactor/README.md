# 커스텀 에러와 검증 리팩터링

## 문제와 시작 상태

상태 코드를 가진 커스텀 에러, 양의 정수 ID 검증 미들웨어, 중앙 에러 핸들러를 구현합니다. 시작 코드는 검증을 건너뛰고 모든 오류를 500으로 처리합니다.

## 수정 파일과 fixture

- 수정: `src/errors.js`
- 정상·오류 ID: `fixtures/ids.json`

## 실행 진입점

`npm run check:15`

## 성공·실패 기준

정상 ID는 숫자로 변환되어 다음 미들웨어로 전달되고 잘못된 ID는 400 커스텀 에러가 되며 알려지지 않은 오류만 안전한 500 응답을 만들면 성공합니다. 중복 직접 응답, 잘못된 상태·본문, 내부 오류 노출은 실패합니다.
