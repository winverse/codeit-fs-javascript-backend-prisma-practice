# 실전 데이터 모델링

## 문제와 시작 상태

영화 예매 시스템의 7개 엔티티, 키, 관계를 Mermaid ER 다이어그램으로 만듭니다. 시작 파일에는 빈 다이어그램만 있습니다.

## 수정 파일과 fixture

- 수정: `diagram.mmd`
- 엔티티·관계·고유 키 요구사항: `fixtures/constraints.json`

## 실행 진입점

`npm run check:04`

## 성공·실패 기준

모든 엔티티에 PK가 있고 FK·고유 키·관계가 요구사항과 같으며 아직 티켓이 없는 상영을 허용하면 성공합니다. 빠진 키·엔티티·관계 또는 `Screening ||--|{ Ticket`처럼 최소 한 장을 강제하면 실패합니다.
