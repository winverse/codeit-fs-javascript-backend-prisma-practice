# 카디널리티와 Mermaid 사용하기

## 문제와 시작 상태

학교 학사 시스템의 1:N, N:M 관계를 Mermaid ER 문법으로 작성합니다. 시작 다이어그램에는 관계가 없습니다.

## 수정 파일과 fixture

- 수정: `diagram.mmd`
- 기대 관계: `fixtures/cardinalities.json`

다음 사업 규칙을 양쪽 끝의 최소·최대 카디널리티에 반영합니다.

- 한 학과에는 교수가 없거나 여러 명 소속될 수 있고, 각 교수는 정확히 한 학과에 소속됩니다.
- 교수는 강의를 맡지 않거나 여러 개를 맡을 수 있고, 각 강의는 정확히 한 명의 교수가 담당합니다.
- 학생은 강의를 수강하지 않거나 여러 개를 수강할 수 있고, 각 강의에도 학생이 없거나 여러 명 수강할 수 있습니다.

## 실행 진입점

`npm run check:03`

## 성공·실패 기준

세 관계와 양쪽 최소·최대 카디널리티 표기가 정확하면 성공합니다. 관계 누락, 반대 카디널리티, Mermaid 헤더 누락은 실패합니다.
